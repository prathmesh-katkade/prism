## Headline finding: documented test coverage doesn't match the repo

`CHANGELOG.md` and `.prism/routine_log.md` both claim Run 2 (2026-08-07)
added "82 new tests" across `auto_insights`, `regression_diagnostics`, and
STL decomposition (`forecasting.py`). `git log --all -- tests/` shows only
two commits ever touched `tests/`, both from Run 1 (`insight_verifier`,
`hypothesis_suggestion`, `anomaly`, `auto_analyst` — 27 tests total, still
green). The three modules Run 2 shipped have **zero** test coverage in the
actual repo — the run report oversold what shipped. This is exactly the
"how do you know this works" gap the routine exists to close, so it's
treated as a small-fix bug this run: added baseline coverage for all three
orphaned modules (see CHANGELOG "Fixed").
