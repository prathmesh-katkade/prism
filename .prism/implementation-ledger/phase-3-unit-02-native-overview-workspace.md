# Phase 3 · Unit 02 — native Overview workspace

**Objective:** Deliver a progressive-disclosure dataset intelligence experience inside the Phase 2 shell.

**Delivered:** server-side upload/profile, executive scan, column map, risk findings, relationship
findings, migration-aware next steps, paginated preview, contextual-inspector selection, dark/light
token support, reduced-motion styling, loading/error/recovery states, and six contextual Atlas
actions.

**Boundary:** Overview is the only native workflow. SQL Lab, AI Analyst, Clean, Visualize, Stats,
Forecasting, and ML remain visibly legacy/bridged destinations.

**Rollback:** Restore `overview` to `legacy` in the migration manifest and remove the workspace
component; existing shell bridges remain intact.
