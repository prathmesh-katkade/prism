# Research — Run 26 (2026-08-12)

Theme this cycle (required): agentic AI analysis — auto-EDA on upload,
automatic insight generation, hypothesis suggestion, anomaly narration.

## Web evidence (5 searches)

1. **"Agentic auto-EDA / run-all one-click automated data analysis 2026"**
   — Confirms "define the goal, provide the dataset, the agent handles
   the rest" is the maturing pattern for agentic EDA tooling in 2026
   (CrewAI-style pipelines: clean → EDA → visualize → summarize →
   report, autonomously chained). Anomalo's April 2026 "Self-Driving
   Data" launch is explicitly framed as "surface what matters without
   waiting for humans to ask" — i.e. the industry direction is *fewer
   manual per-check button clicks*, not more detectors.
   [KDnuggets](https://www.kdnuggets.com/5-agentic-workflows-to-automate-your-data-science-pipeline),
   [BigDATAwire/Anomalo](https://www.hpcwire.com/bigdatawire/this-just-in/anomalo-launches-agentic-self-driving-data-system-to-automate-data-operations/)
2. **Julius AI / ChatGPT Advanced Data Analysis, 2026** — Julius
   "generates a full EDA with distributions, correlations, missing
   values, and outlier summaries in one prompt after upload," beating
   ChatGPT ADA on first-pass tidy-CSV polish (14/18 vs 9/18 in a 2026
   comparison). The competitive bar is a *single action* producing a
   multi-faceted result, matching what Prism's own detector bench
   (auto_insights/hypothesis_sweep/anomaly/orchestrator) already computes
   but currently gates behind 2+ separate manual tab visits.
   [buildmvpfast](https://www.buildmvpfast.com/articles/best-llms-2026-guide/data-analysis-ai),
   [infinisynapse](https://infinisynapse.com/en/blog/julius-ai-vs-chatgpt)
3. **Data analyst interview trends, 2026** — Hiring signal is shifting
   toward "automated data quality alerts for null rates, anomalies, or
   sudden drops" and demonstrated automation of repetitive analysis
   steps, not raw EDA syntax recall.
   [KORE1](https://www.kore1.com/data-analyst-interview-questions-2026/),
   [DataCamp](https://www.datacamp.com/blog/how-to-prepare-for-a-data-analyst-interview)
4. **Gemini 2.5 Flash free tier limits, 2026** — Free tier is roughly
   10-15 RPM / ~250k-1M TPM / 500-1500 RPD depending on source, resets
   daily at midnight Pacific; the practical constraint for an
   interactive app is RPM/RPD, not TPM. Confirms the existing app-wide
   convention (cache narration by content fingerprint, one call per
   distinct result, graceful fallback text on 429/quota errors) is
   still the right design and that any new feature must not add
   *automatic* Gemini calls that fire without a user action.
   [aifreeapi](https://www.aifreeapi.com/en/posts/gemini-api-free-tier-rate-limits),
   [rapidevelopers](https://rapidevelopers.com/ai-api-limits-performance-matrix/gemini-2-5-flash)
5. **Hex / Deepnote 2026** — Both ship an agent that chains multiple
   analysis steps from one instruction ("Notebook Agent"); anomaly
   diagnosis and AI-interpreted insights are now baseline expectations,
   not differentiators. Reinforces that Prism's differentiator isn't
   *having* these detectors (it already does, extensively) but *not
   requiring per-detector manual triggering* to get their combined view.
   [Hex blog](https://hex.tech/blog/introducing-notebook-agent/),
   [Niblin](https://niblin.com/blog/best-data-agent-platforms-2026)
