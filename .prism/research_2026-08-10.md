## Key findings

- **Agentic EDA research** (arXiv 2508.02744 "LLM-based Data Science Agent:
  A Survey"; arXiv 2605.07202 "Data-to-Insight Discovery Agent") — the
  emerging pattern is small, composable, *self-verifying* agent steps
  (state modeling → targeted insight discovery → verification) rather than
  one big prompt. Prism already has the verification half
  (`insight_verifier.py`, Run 1) and the "scan → rank → optionally narrate"
  half (`auto_insights.py`, Run 2). The gap: narration is opt-in and
  reactive (button click) everywhere it exists — nothing in Prism narrates
  or surfaces *unprompted*, which is exactly what "agentic" and "JARVIS
  copilot" both call for.
- **Job market** (AccioJob/Dataquest/Loopcv 2026 breakdowns): SQL and
  pandas remain the highest-leverage skills; "AI-assisted analysis
  familiarity" is now explicitly called out as a differentiator, not just
  a nice-to-have. Confirms the routine's existing agentic-AI priority
  theme is well-aimed — no new pivot needed.
- **Competitor tools**: unchanged from the 2026-08-07 research doc — Hex/
  Deepnote's magic AI cells still run detection→narration as one visible
  step; none of them surface *proactive* alerts the way a copilot assistant
  (Copilot in Office, Clippy-successor patterns) does. A visible "I noticed
  something" affordance without a click is a genuine differentiator for a
  portfolio piece, not just a copy of what's already out there.
