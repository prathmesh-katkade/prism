  `modules/stats_lab.py`, and `modules/mllab.py` for a code-level audit
  (Streamlit itself needs a real browser session to click through — Playwright

- **Gap confirmed, not previously logged this precisely:** Stats Lab
  (`modules/stats_lab.py`) only supports testing *one manually-chosen pair*
  of columns at a time (`suggest_test` + `run_test`). There is no automated
  sweep across all column pairs, and therefore no multiple-testing
  correction anywhere in the app — a dataset with 10 numeric columns has 45
  possible pairs; testing them one-by-one at raw α=0.05 without correction
  is exactly the kind of implicit p-hacking a data science interviewer would
  flag. This is the basis for this run's agentic-theme feature (see
  research file).
- Environment-only observation (not a code bug): `requirements.txt` installs
  cleanly; the cffi/cryptography issue above is specific to this execution
  container's base image, not the repo — no action needed in-repo, noting it
  here only so a future run isn't surprised by the same test-collection
  error and doesn't waste time thinking it's a regression.
