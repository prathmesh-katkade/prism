## Why Insight Verifier was picked over the others
- It's the only candidate that's a *direct, load-bearing* answer to this
  cycle's mandatory priority theme (agentic AI analysis) with real
  statistical-rigor depth — not a UI convenience layer.
- It's genuinely differentiated versus the competitor set in the brief
  (Hex/Deepnote/Julius/ChatGPT-ADA/Databricks Assistant): none of them
  visibly fact-check their own LLM narration against the source data in
  a way the user can see per-finding.
- Effort/risk profile fit a full-auto unattended run: deterministic, pure
  functions, easy to unit test exhaustively, zero new external API calls
  (stays inside Gemini free-tier limits trivially — it doesn't call
  Gemini at all).
