## Small fixes made alongside the main feature (see routine log / CHANGELOG)
- `experiment_design._round_up()` hardened against `statsmodels.stats.
  power`'s `solve_power()` occasionally returning a size-1 numpy array
  instead of a plain float (depends on which internal root-finder path it
  took) — was producing a `DeprecationWarning` (`Conversion of an array
  with ndim > 0 to a scalar is deprecated`) under pytest for chi-square

  the t-test path just never happened to hit the array-return branch.
